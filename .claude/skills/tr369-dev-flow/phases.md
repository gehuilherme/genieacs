# PRs — phasing & definition of done

Each PR is independently shippable. CWMP must stay 100% functional after every
PR.

## PR1 — Foundation

**Code**:

- `proto/usp/usp-msg-1-3.proto` + `proto/usp/usp-record-1-3.proto` (verbatim
  from Oktopus, BBF header retained)
- `lib/usp/proto/*.ts` (generated by ts-proto, committed)
- `lib/common/xsd.ts` (extracted from `lib/soap.ts:171-201`, soap.ts re-imports
  it)
- `lib/db/types.ts`: add `_protocol`/`_usp` to Device shape, add
  `TaskOperate`/`TaskAddSubscription`/`TaskRemoveSubscription` to union, add
  `protocol?` to TaskBase
- `lib/usp/types.ts`, `lib/usp/endpoint.ts` (parser + CWMP reconciliation)
- `lib/mtp/types.ts`, `lib/mtp/subjects.ts`, `lib/mtp/nats.ts`
- `bin/genieacs-usp-controller.ts` skeleton (decode→resolve→log; no MTP yet)
- `bin/genieacs-migrate.ts` (one-off: set `_protocol:'cwmp'` on existing docs)
- `build/build.ts`: add 4 binaries to `services` array
- `package.json`: deps `nats`, `protobufjs` (runtime proto parsing — no protoc required)
- `deploy/Dockerfile` + `deploy/docker-compose.dev.yaml` +
  `deploy/{mosquitto,nats}/` configs

**Docs**:

- `docs/usp/index.rst`, `overview.rst`, `architecture.rst` (with ASCII diagram),
  `data-model.rst`, `configuration.rst` (skeleton)
- Update `docs/index.rst` toctree
- Update `docs/environment-variables.rst` with `NATS_*` keys

**Skill**: `.claude/skills/tr369-dev-flow/` (this directory) ships in PR1

**Definition of done**:

- `npm run build` succeeds (proto schemas embedded via esbuild text loader)
- `npm run lint` zero warnings
- All existing CWMP tests still pass
- `docker compose -f deploy/docker-compose.dev.yaml up` brings up the stack
  (controller will idle without MTPs — expected)
- A unit test injects a fake Boot Notify into NATS, controller writes a device
  with `_protocol:'usp'` to Mongo
